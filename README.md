## Kebutuhan Proyek

### Membangun Data Warehouse (Data Engineering)

#### Tujuan
Membangun data warehouse sederhana menggunakan SQL Server untuk menggabungkan data penjualan, sehingga bisa dipakai untuk pelaporan analitik dan membantu pengambilan keputusan.

#### Spesifikasi
- **Sumber Data**: Mengimpor data dari dua sistem sumber (ERP dan CRM) dalam format file CSV.
- **Kualitas Data**: Membersihkan dan memperbaiki masalah kualitas data sebelum dianalisis.
- **Integrasi**: Menggabungkan kedua sumber data menjadi satu model data yang mudah dipakai untuk query analitik.
- **Cakupan**: Hanya menggunakan dataset terbaru; historisasi data belum diperlukan.
- **Dokumentasi**: Menyediakan dokumentasi model data yang jelas agar mudah dipahami oleh pembaca maupun tim analitik.

---

### BI: Analitik dan Pelaporan (Analisis Data)

#### Tujuan
Membuat analisis berbasis SQL untuk mendapatkan insight tentang:

- **Perilaku Pelanggan**
- **Performa Produk**
- **Tren Penjualan**

Insight ini diharapkan membantu pemangku kepentingan memahami metrik bisnis utama dan mengambil keputusan yang lebih tepat.
